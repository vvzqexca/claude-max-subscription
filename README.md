## 用量限制怎么算：5 小时 + 每周两套账

Max 的用量限制是两层。第一层是会话限制，每 5 小时重置一次，5x 和 20x 的差距主要体现在这一层。第二层是每周限制，跨所有模型计算，每周在你账户绑定的固定时间重置——不是按你订阅那天算。下次重置时间在设置里的 Usage 页面能直接看到。

用 Haiku 5.5 还要小心一个价格悬崖：提示词在 10 万 tokens 以内是 0.10/0.50 美元每百万，一旦超过 10 万，直接涨到 0.50/2.50，翻五倍。提示词长度把缓存读取也算进去，且每个请求单独计价——10 万 tokens 一次调用花 0.011 美元，100,001 tokens 就变成 0.055 美元。长对话 agent 跑着跑着上下文过了这条线，便宜模型就悄悄不便宜了，记得及时裁剪或摘要历史。

最常见的三种浪费也顺带说一句：所有请求默认最贵模型；能缓存（命中价约为基础输入的 0.05 倍）、能走批量 API（半价）的场景硬跑实时；以及放着不管等清零——额度只用掉三成，等于白扔 140 美元。

## 常见问题

**Max 有年付吗？**
没有，两档都只提供月付。

**官方有折扣码或常设优惠吗？**
没有。官方帮助文档写明不提供标准折扣价，偶尔会有限时活动，客服也无法发放一次性优惠码。想蹲促销只能关注官方渠道的通知。

**用量限制多久重置一次？**
会话限制每 5 小时一次；周限制每周在账户绑定的固定时间重置，具体时间在 Settings 的 Usage 页面查看。

**每月 API 额度能攒着下个月用吗？**
不能，周期结束就清零。取消或降级套餐后，已到账的额度还能用到过期，但不再发放新的。

**撞到限额怎么办？**
等下一次重置，或者用 limit reset 把会话/周限额恢复满额。20x 档额度大，撞线的概率比 Pro 低得多。

**升级、降级怎么计费？**
升级立即生效、按比例补差价；降级下个周期生效，当期权益用完为止。
